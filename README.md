# Verificador de códigos QR

Esta aplicación es un prototipo realizado con Copilot para el
[HackaITVer 2026](https://hackaitver.cis-itver.net/) en la categoría de
Mecatrónica e Industrial. Se propuso utilizar lectores QR conectados a la
red del sistema de distribución del CIDES descrito. Este repositorio sirve
solo para vender la idea del funcionamiento de los lectores QR.

Se utilizó IA por razones de tiempo.
